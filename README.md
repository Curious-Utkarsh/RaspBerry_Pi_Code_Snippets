# Raspberry Pi Snippets (2023–2025)

Reference scripts for the Raspberry Pi: GPIO, sensors, servos and the camera, including face tracking on a pan-tilt mount and on-device object detection with TensorFlow Lite.

| Topic | Scripts |
|---|---|
| GPIO basics | `blink_led.py`, `ledBlink.py`, `pwmLed*.py`, `button_press*.py`, `buttonLed.py`, `gpioInput.py`, `internalPullUp.py`, `toggleSwitch.py` |
| Sensors and actuators | `pirSensor.py`, `pir_sensor_alarm.py`, `ultraSonic.py`, `servo*.py` |
| Camera | `preview.py`, `still_picture.py`, `series_pictures.py`, `record_video.py`, `adjust_brightness*.py`, `effects_loop.py`, `annotate.py`, `change_resolution.py` |
| Vision | `camTrackFace.py`, `panTiltTrackFace.py`, `camPanTiltTrack.py`, `bodyLandMarks.py`, `tfDetect.py` / `detectTF.py` (TFLite EfficientDet-Lite0), `object_audio.py`, `ocr_audio.py` |
| Setup | `instructions.md`, `webcam.sh` |
